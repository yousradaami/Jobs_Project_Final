# Global IT Job Market Analysis

## 1. Project Overview
This project focuses on analyzing the global Information Technology (IT) job market, with particular attention to remote job opportunities.

The main objective is to identify the most demanded technical skills and analyze how skill requirements vary according to job experience levels and job categories.

## 2. Dataset
The dataset contains **2,000 real IT job advertisements** collected from several online job platforms through web scraping.

The collected data includes:
- Job Title
- Location
- Categories
- Experience Level
- Required Skills

## 3. Data Sources
The project uses job advertisements collected from:
- Himalayas
- We Work Remotely
- Remote OK
- Remotive

## 4. Technologies and Libraries
- Python
- Pandas
- Requests
- BeautifulSoup / XML processing
- Matplotlib
- Scikit-learn
- Excel and CSV

## 5. Project Workflow
1. **Web Scraping:** Collecting real IT job advertisements from online platforms.
2. **Data Cleaning:** Handling missing values, duplicates, and text formatting.
3. **Data Preprocessing:** Extracting and organizing relevant information, including experience levels and required skills.
4. **Data Analysis:** Studying job categories, experience levels, and demanded technical skills.
5. **Data Visualization:** Creating charts to present the main findings.
6. **Machine Learning:** Applying clustering techniques to explore similarities between job advertisements.

## 6. Main Research Questions
- What are the most demanded technical skills in the global IT job market?
- Which skills are required for different experience levels?
- How do required skills differ across IT job categories?
- What are the main patterns among remote IT job advertisements?

## 7. Final Dataset
The organized dataset is available in two formats:
- `jobs_final_5_columns.csv`
- `jobs_final_organized.xlsx`

Both files contain 2,000 records and five columns.
